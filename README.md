# 百人一首歌牌学习

中文百人一首学习网页：原文、假名、中文意译、初始决字、配对练习及错题复习。

日文使用内嵌 Shippori Mincho 明朝体，诗句与取札采用右起竖排。学习记录保存在浏览器，可导出和导入备份。

## 编辑与构建

修改 `index.html.in` 或 `poems.json` 后运行：

```sh
python3 build.py
```

直接打开 `index.html`，或通过 GitHub Pages 访问。

原诗为公版古典文学；资料来源见页面入门指南和 `sources.json`。字体采用 SIL Open Font License 1.1，见 `OFL.txt`。
